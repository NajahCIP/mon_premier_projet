Synthèse du code HTML/CSS – Carte de présentation

Ce document résume le fonctionnement du code de la carte professionnelle réalisée en HTML et CSS pour être affichée sur une page web ou dans VS Code.

🔧 Structure générale

Le fichier contient :

  • HTML : structure du contenu (carte, titre, image, services, contact)
  • CSS : mise en forme visuelle (couleurs, ombres, typographie, boutons, etc.)

🏗 Contenu principal de la carte

La carte contient :

  • Un titre principal et un sous-titre
  • Un paragraphe de description
  • Une section Mes services sous forme de liste
  • Des boutons de contact (téléphone + mail)

🎨 Principaux éléments CSS utilisés

- background-color : définit les couleurs de fond
- border-radius : arrondit les bords de la carte et de l’image
- box-shadow : ajoute une ombre autour de la carte
- font-family : applique les polices importées
- linear-gradient : crée un bandeau décoratif doré en haut de la carte
- transition : anime le survol des boutons

📱 Responsive Design (design réactif)

Le code utilise display:flex et min-height:100vh pour centrer la carte, ce qui permet une adaptation sur téléphone ou tablette.

📂 Ce que l’on peut modifier facilement

  • Le titre, sous-titre, description
  • Les services dans la liste
  • Le numéro de téléphone et l'email
  • Les couleurs dorées (#d4a574, #f4d03f) si besoin

🎯 Objectif de la carte

Cette carte web peut servir de :

  • Carte de visite numérique
  • Présentation professionnelle (LinkedIn, Portfolio, QR Code…)
  • Support
