HTML, CSS, CMS & Cycle de vie d’une application web

1) Rôles et différences de HTML et CSS

HTML

Rôle : Structurer le contenu d’une page web.

Exemples : créer des titres, paragraphes, images, listes.

Analogie : HTML, c’est comme les murs et les meubles d’une maison → Il permet de construire la structure.

CSS

Rôle : Styliser et embellir le contenu.

Exemples : modifier les couleurs, la taille du texte, la police, les marges, l’arrière-plan.

Analogie : CSS, c’est comme la peinture, les rideaux et la décoration → Il rend la page agréable à regarder.
HTML = structure | CSS = design

2) Différence entre un langage de balisage et un langage de programmation

Langages de balisage (HTML/CSS)

But : décrire et afficher des informations.

Exemple : créer une page web avec du texte et des images.

Analogie : comme un livre avec des chapitres et des illustrations.

Langages de programmation (Python, JavaScript, etc.)

But : automatiser, calculer, prendre des décisions.

Exemple : créer un jeu, analyser des données, gérer une base de données.

Analogie : comme un chef cuisinier qui suit une recette et adapte les ingrédients selon la situation.
HTML/CSS affichent du contenu — Python le fait fonctionner et réagir.

3) Qu’est-ce qu’un CMS ?

Définition : Un CMS (Content Management System) est un outil qui permet de créer, gérer et modifier facilement le contenu d’un site web sans coder.

Exemples :

  • WordPress
  • Joomla / Drupal
  • Shopify

Avantages :

  • Facile à utiliser, même sans compétences techniques.
  • Rapide pour créer un site.
  • Extensions pour ajouter des fonctions.
  • Travail collaboratif possible.

Inconvénients :

  • Personnalisation limitée sans coder.
  • Peut présenter des failles de sécurité si mal géré.
  • Peut devenir lent avec trop de plugins.
Analogie : Un CMS, c’est comme utiliser un modèle de CV déjà prêt : il suffit de remplir les informations.

4) Cycle de vie d’une application web

  1. Idée : définir le but du site.
  2. Conception : faire des maquettes et organiser les pages.
  3. Développement : écrire le code (HTML, CSS, JavaScript...).
  4. Test : vérifier le bon fonctionnement.
  5. Mise en ligne : publier le site.
  6. Évolution : ajouter des fonctionnalités, corriger des bugs.
Comme construire une maison : imaginer → faire les plans → construire → vérifier → emménager → ajouter une piscine plus tard.

📌 Synthèse express à retenir

  • HTML = structure de la page
  • CSS = style et design
  • Langage de balisage = présente le contenu
  • Langage de programmation = fait fonctionner le système
  • CMS = créer un site sans coder
  • Une application web évolue comme une maison qu’on améliore
